# Chauves Célèbres 🌟

Site vitrine ludique dédié aux chauves : origine du mot « chauve », galerie illustrée et célébrités chauves.

## Voir le site en local

Ouvre simplement `index.html` dans un navigateur, ou lance un petit serveur local :

```bash
python3 -m http.server 8000
```

## Déploiement GitHub Pages

1. Va dans **Settings → Pages** du repo.
2. Source : **Deploy from a branch**.
3. Branche : `main`, dossier : `/ (root)`.
4. Enregistre — le site sera disponible à `https://<utilisateur>.github.io/<repo>/`.
